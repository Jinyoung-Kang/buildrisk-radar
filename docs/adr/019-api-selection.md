# ADR-019 추가 공공 API 선택 — 쓴 것과 쓰지 않은 것

검증된 키 20여 종 중 이 서비스의 질문 — **"건설사의 재무·사업 위험이 어느 지역 주택시장과 얽혀 있는가"** — 에 답을 보태는 것만 골랐다.
키가 있다는 이유로 붙이면 화면은 화려해져도 판단 근거는 흐려진다.

| API | 결정 | 이유 |
|---|---|---|
| 국토부 아파트 매매 실거래가 | **사용** (ADR-015) | 거래량·해제율은 가격지수보다 먼저 움직이는 지역 신호. 시군구 코드가 기존 경계 코드와 같아 매핑 비용이 없음 |
| 금융위 주식시세 | **사용** (ADR-017) | 경보 품질을 사후 검증할 수 있는 유일한 시장 데이터 |
| Open DART document.xml | **사용** (ADR-016) | 이미 가진 키로 수주 지역·보증 잔액을 얻음 — 기업 × 지역을 잇는 핵심 |
| 기상청 단기·중기예보 · 에어코리아 | 사용 안 함 | 공사 일정 리스크와는 관련이 있으나 기업 재무 위험·주택시장 경보와 인과를 세울 근거 데이터가 없음 |
| 한국도로공사 · 코레일 · TAGO 열차/지하철 · 서울 노선 | 사용 안 함 | 교통 접근성은 입지 분석 주제. 월 단위 시장 지표와 결합할 기준이 이 범위 밖 |
| 약국 · 병의원 · e약은요 | 사용 안 함 | 주제와 무관 |
| 특일 정보 | 사용 안 함 | 백테스트는 주가 원천에 있는 날만 거래일로 쓴다(실데이터 3.1만 행 중 주말 0행) — 따로 달력을 둘 필요가 없음 |
| 우체국 · 우정사업본부 도로명주소 | 보류 | 공시 주소 → 시군구 해석 정확도를 높일 수 있음. 현재 규칙 기반 해석으로 충분한지 매핑 결과(시군구 · 시도만 · 해외 · 불가 비율)를 먼저 본 뒤 결정 |
| 카카오 로컬 | 보류 | 위와 같음 (지오코딩) |
