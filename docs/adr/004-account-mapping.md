# ADR-004 계정 매핑: account_id 우선, 계정명 보조

**결정** `ref.account_map` 규칙을 우선순위(낮을수록 먼저)로 적용한다. `ACCOUNT_ID`(IFRS 태그) → `NAME_EXACT` → `NAME_REGEX`. 계정명은 공백·앞 번호(Ⅰ. 1. (1) 가.)·주석 표시를 지운 뒤 비교한다. 표준계정마다 `FIRST`(가장 앞선 규칙의 첫 행) 또는 `SUM`(서로 다른 매칭 행의 합, 예: 단기차입금 + 유동성장기부채) 집계를 쓴다.

**이유** 응답에 `account_id` 와 `account_nm` 이 모두 있지만(E16) 회사마다 표준계정코드를 안 쓰는 행("-표준계정코드 미사용-")이 많다.

**이자비용(U-6)** 손익계산서 본문에 없는 회사가 많아, 현금흐름표 "이자의 지급"(절댓값)을 낮은 우선순위 대체로 둔다. 어느 출처를 썼는지는 `fs_std.source_sj_div` 와 경보 근거에 남는다. 둘 다 없으면 이자보상배율은 `MISSING`.

**실데이터로 추가한 규칙 (2026-09-24, [VERIFICATION](../VERIFICATION.md) 7~12)**
- **부채 구간 판별**: 재무상태표 행 순서에서 가장 가까운 앞쪽 '유동부채'·'비유동부채' 제목으로 구간을 정하고, 구간 조건이 붙은 규칙(`section`, V6)으로
  '유동 차입금(사채 포함)' · '차입금등(비유동)' 같은 표기 변형을 단기/장기차입금에 나눈다. 43개사 기준 단기 81.6→90.3%, 장기 68.2→79.4%.
- **순액·액면 이중 공시**: SUM 계정은 바로 앞 줄과 이름이 같으면 액면 줄로 보고 제외(떨어진 같은 이름 — 유동/비유동 '회사채' — 은 합산).
- **한 원천 행은 한 표준계정에만**: 표준계정 순서대로 먼저 가져간 행은 다른 계정이 다시 쓰지 않는다.
- **대체 규칙**: 우선순위 50 이상은 본 규칙에 걸린 행이 하나도 없을 때만 쓴다(예: 차입금 대신 '단기금융부채').
- 이 규칙들은 실제 응답 6건의 골든 테스트(회계 항등식 · 차입금 ≤ 부채 · 스냅샷)로 고정한다.
