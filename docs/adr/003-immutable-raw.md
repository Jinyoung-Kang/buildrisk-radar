# ADR-003 재무 원천 불변 + 표준화 재생성

**결정** `dart.fs_raw` 는 INSERT ... ON CONFLICT DO NOTHING 만 한다. 정정공시는 새 접수번호(rcept_no)로 새 행이 쌓이고, 표준화는 (기업, 연도, 보고서, 연결/별도)마다 최신 접수번호를 쓴다. `dart.fs_std` 는 언제든 지우고 다시 만드는 파생 테이블이다.

**이유** 매핑 규칙을 고치거나 추가해도 API 를 다시 부르지 않고 원천에서 재생성할 수 있다(FR-206). 원천이 변하지 않으므로 지표·경보 → 표준계정 → 원천 행 → 접수번호로 거슬러 올라갈 수 있다(NFR-04).
