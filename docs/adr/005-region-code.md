# ADR-005 내부 기준 시군구 코드 + 출처별 매핑표

**결정** 경계 데이터의 5자리 코드를 기준 `region_cd` 로 쓰고, KOSIS·R-ONE·SGIS 의 지역 코드는 `ref.region_code_map` 을 거쳐 한 번 통일한 뒤 저장한다. 매칭은 '시도 약칭 + 시군구 이름'(seed/region_aliases.yml)으로 하고 결과(NAME · MANUAL · AGGREGATE · UNMAPPED + 사유)를 모두 남긴다.

**실측으로 확인한 차이 (2026-09-24)**
- KOSIS 미분양은 시 단위(수원시), SGIS 는 일반구 단위(수원시 장안구), R-ONE 은 권역 경로(경기>경부1권>안양시>만안구).
  → 일반구(level 3)를 합친 합성 시(level 2, synthetic)를 만들고, 합계형은 SUM(모든 하위 구가 있을 때만), 지수형은 MEAN 으로 모은다.
- KOSIS 는 2026-07 광주·전남 통합을 반영해 시도명 "전남광주"를 쓴다 → 후보 시도 두 개에서 찾는다.
- V-World 경계는 이미 2026-07 개편(전남광주통합특별시, 인천 신설 구)을 반영했다. 그래서 KOSIS 의 신설 구는 매핑되고,
  반대로 **폐지된 옛 구**(인천 중구·동구·서구)의 과거 KOSIS 시계열과 SGIS 2024 총가구가 미매핑(사유 기록)이 된다.
- seed 의 수동 항목은 `regionCd` 가 있으면 강제 매핑, 없으면 **이름으로 못 찾았을 때 붙이는 사유**로만 쓴다(경계가 갱신되면 자연히 매핑되도록).
- R-ONE 의 '전국'·'수도권'·'5대광역시' 같은 최상위 합계는 AGGREGATE 로 분모에서 제외한다.
- 결과: KOSIS 98.8% · R-ONE 100% · SGIS 98.8% (FR-401 기준 ≥ 98%).
