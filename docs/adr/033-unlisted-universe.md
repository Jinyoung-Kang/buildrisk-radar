# ADR-033 비상장 건설사를 유니버스에 — DART 로 분기 재무가 오는 곳만, 금융위 기업재무정보는 쓰지 않음

**왜** 유니버스는 '업종코드 41 · 421 의 유가 · 코스닥 상장사 + 수동 포함'(43개사)이었다. 그런데 시공능력평가 상위 건설사 다수가 비상장이다
(2026 시평 100위 안 65곳 — 4위 현대엔지니어링 · 7위 롯데건설 · 8위 포스코이앤씨 · 9위 SK에코플랜트). 이들은 PF · 분양 위험의 큰 축이고,
청약홈 분양 공고(ADR-032)의 시공사로도 자주 나온다.

**조사 (2026-10-19, 저장소 변경 없음 — [계획 B-5](../review/2026-10-18-new-public-api-plan.md))**
- DART `fnlttSinglAcntAll` 2025 사업보고서: 비상장 후보 40곳 중 **9곳**만 자료가 온다(사업보고서 제출 대상 — 공모사채 발행 등). 확인한 3곳은 2026 반기보고서도 있다.
  나머지 31곳과 2024~2026 회생 · 워크아웃 기업 8곳은 감사보고서만 내 013(자료 없음).
- 금융위원회 기업재무정보 · 기업기본정보(공공데이터포털): 키는 승인됐지만 DART 에 없는 17곳 중 쓸 만한 자료는 1곳 — 5곳은 `fnclDcd=999` 행만(영업이익 0 · 자본 = 자산 ·
  원문 감사보고서와 불일치), 11곳은 없음. 재무상태표 9개 · 손익 5개 계정뿐(차입금 · 사채 · 이자비용 · 현금흐름 없음), `basDt` 는 결산일(공개일 아님 — point-in-time 불가).

**결정**
1. DART 로 분기 재무가 오는 비상장 9곳을 `seed/universe_overrides.yml` 의 include 로 넣는다(사유를 줄마다). 정책(`UniversePolicy`)은 그대로 — 수동 포함이 상장 여부보다 앞선다.
2. 기업개황 수집 대상에 '대상 기업 · 수동 포함'을 더한다(전에는 종목코드가 있는 회사만 — 비상장은 업종 · 주소 없이 유니버스에 들었을 것). 법인등록번호 · 사업자등록번호를 저장(V23, 공개 정보).
3. **'상장' = 기업개황 `corp_cls` 가 유가(Y) · 코스닥(K)**. corpCode.xml 은 상장폐지된 회사에도 종목코드를 남기므로(두산건설 · 신세계건설 · 경남기업, corp_cls E) 종목코드로 판단하지 않는다 —
   주가 수집 · 백테스트 · 주가 탭은 지금 상장만. 화면은 종목 대신 '비상장', 주가·경보 탭을 숨긴다. API 에 `listed`(기업 목록 · 요약)를 더함(v1 '더하기만').
4. 금융위 경로(계획 B-3)는 만들지 않는다 — ADR-019 에 '사용 안 함'.

**그대로 되는 것** 재무제표 · 표준화 · 지표 · 재무 규칙(R-C01~C03) · 공시 · 원문 구조화(수주 · 보증) · PF 우발채무(정기보고서) · 청약홈 시공사 대조는 DART 자료라 상장사와 같은 경로.
비상장 9곳의 청약홈 표기 중 같은 이름이 여러 법인인 3곳(현대엔지니어링 · 두산건설 · 경남기업)과 옛 이름 · 영문 표기(포스코건설 · SK에코플랜트 · BS한양)는 브랜드로 확인해 별칭에 더했다.

**한계** 감사보고서만 내는 대형 비상장(호반 · 중흥 · 대방 · 우미 · 제일 등)과 회생 기업은 여전히 빠진다 — 남은 길은 감사보고서 원문 파싱(별도 결정).
비상장은 주가가 없어 백테스트 · 주가 반응에서 빠지고, 거래소 공시(R-C04 의 일부 유형)는 없을 수 있다. 성적표 모수에는 들어간다(DART 공시로 '알게 된 날'이 정해짐).

**실데이터 결과** VERIFICATION 9차.
